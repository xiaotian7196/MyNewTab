# Homepage

Homepage 是一个简洁的液态玻璃风格浏览器新标签页扩展。它使用原生 HTML、CSS 和 JavaScript 编写，不依赖构建工具。

项目地址：<https://github.com/xiaotian7196/MyNewTab>

## 安装

### Chrome / Edge

打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，然后选择项目文件夹。

也可以使用项目中的 `Homepage.crx`、`Homepage-Liquid-Glass.zip`。Chrome/Edge 可能要求开发者模式，Chrome Web Store 安装还需要官方签名。

### Firefox

打开 `about:debugging#/runtime/this-firefox`，选择「临时载入附加组件」，然后选择 `Homepage-Liquid-Glass.xpi`。

Firefox 正式版通常要求 Mozilla 签名，未签名 XPI 只能临时加载。

安装后第一次打开新标签页时，Homepage 会询问是否继续使用此页面。选择「暂不同意」会恢复安装前保存在本地的设置。

## 功能

- 接管浏览器新标签页，名称为 Homepage。
- 支持 Google、百度、必应、DuckDuckGo、搜狗、360 搜索、知乎和 GitHub。
- 可以在设置中添加自定义搜索引擎，搜索地址使用 `%s` 代表关键词。
- 搜索框支持网址直达、搜索推荐、本页搜索记录和浏览器历史记录建议。
- 浏览器历史记录默认关闭，最多显示 4 条，必须经过用户授权后才会读取。
- Google 支持图片搜索，可以粘贴图片链接或选择本地图片打开 Google Lens。
- 支持快捷网址的添加、编辑、删除和拖动排序。
- 快捷网址栏**顶层只放文件夹**，网址都收在文件夹里面。
  **左键点文件夹会在原位横向展开**里面的网址（就排在该文件夹后面，其余文件夹顺推向右），再点一次收起。
  **右键文件夹可以一次打开里面全部网页**，展开组末尾也有一个「全部打开」；
  编辑模式下可以拖动网址调整顺序、把网址拖到别的文件夹上移过去、拖动文件夹调整先后；
  双击可以重命名文件夹或修改网址，删除非空文件夹会先确认。
- 老版本里散在顶层的网址，首次打开时会自动收进一个「未分类」文件夹，不会丢数据。
- 支持上传背景图片、背景淡化、深色模式、浅色模式、字体和面板透明度设置。
- 设置面板分为常规、搜索、外观和隐私四个选项卡。
- 设置面板使用窄型玻璃滚动条，不会让上下滚动按钮越出圆角边框。

## 设置同步

在同一个浏览器账户中，部分偏好会通过浏览器提供的 `storage.sync` 同步。

Firefox、Edge 和 Chrome 使用不同的浏览器账户同步空间，不能仅凭同一台电脑自动互通。因此设置中的「导出设置」和「导入设置」可以用来在三个浏览器之间迁移设置。背景图片也会包含在导出的本地 JSON 文件中。

导入和导出都在本地完成，不会上传到项目服务器。

## 隐私说明

- 扩展没有后台联网任务。
- 搜索提交时会访问用户选择的搜索引擎。
- 搜索推荐会访问当前选择的搜索引擎建议接口。
- 网站图标可能访问 Google 或 DuckDuckGo 的 favicon 服务。
- 一键打开文件夹内的多个网页时，会逐个打开新标签页；在扩展环境下使用浏览器标签页接口，不经过弹窗拦截。
- 背景图片保存在浏览器本地，不上传到开发者服务器。
- 页面设置和本页搜索记录保存在浏览器本地。
- 浏览器历史记录默认关闭，只有用户主动授权后才会用于搜索建议。
- 扩展不会修改、删除或上传浏览器历史记录。
- 搜索引擎、Google Lens 和 favicon 服务的处理方式以各自隐私政策为准。

本项目按数据最小化、用途限定、用户选择和透明告知原则设计，可作为 CCPA/CPRA、Firefox 和 Chrome 隐私披露的工程基础。但这不是法律意见，也不代表获得政府、Mozilla、Google 或 Chrome Web Store 的官方认证。正式商业发布前应由合格律师和平台审核人员检查。
